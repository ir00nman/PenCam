# PenCAM

**Однофайловый браузерный CAM и отправщик G-code для рисования ручкой на ЧПУ 3018 (GRBL). Теперь с цветным рисованием многоцветной ручкой.**

---

## Что это?

PenCAM превращает фрезер (например, 3018 и любой  GRBL) в плоттер. Откройте сайт (Deployments => Last deployments), загрузите изображение, сгенерируйте G-code и отправьте его на станок через Web Serial. Без сервера, без зависимостей, без установки.

## Вкладки

| Вкладка              | Что делает                                                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| ✦ **Редактор ручки** | Режим одной ручки: градации серого → выделение краёв (порог + гистерезис) → линии → G-code                                                  |
| 🖍 **Цветная ручка** | Мультицветный режим с 8-цветной ручкой (см. ниже)                                                                                           |
| ⇄ **Конвертер**      | Конвертация готового лазерного G-code в G-code для рисования ручкой                                                                         |
| ⌖ **Станок**         | Подключение, джог, размещение на рабочем поле, отправка, управление по слоям, клик по полю и станок едет в эту точку (всё как в других CAM) |

## Режим цветной ручки

Идея: чернила на бумаге не смешиваются как точки принтера, поэтому вместо смешивания цветов PenCAM **выбирает одну ручку на область** и передаёт тон **плотностью штриховки**.

**Конвейер обработки**

1. RGB → **CIELab** (с учётом sRGB-гаммы)
2. Коррекция светлоты / контраста / насыщенности в Lab (насыщенность регулируется по a/b независимо от L)
3. Сглаживание шума
4. Ближайшая ручка для каждого пикселя по **ΔE** (перцептивное расстояние между цветами)
5. Мода-фильтр + слияние мелких областей с соседними
6. Прозрачный фон PNG обрабатывается через альфа-канал, поэтому он никогда не путается с настоящим чёрным цветом на рисунке
7. Слои по цветам → штриховка заливки (шаг по умолчанию 0,3 мм) + контурные обводки
8. G-code по слоям с паузой (`M0`) перед каждым цветом и уведомлениями на экране

**Возможности**

- **Сплошная заливка + обводка**: настраиваемое число концентрических обводок, обводка отступает внутрь на половину толщины пера (настройка толщины пера, по умолчанию 0,7 мм, лучше поставить 0.), чтобы соседние цвета не накладывались
- **Штриховка по яркости** (опционально): тёмные участки цвета получают больше чернил, либо **перекрёстной штриховкой**, либо **более частыми параллельными линиями**
- **Оптимизация пути**: упорядочивание штрихов методом ближайшего соседа, непрерывная штриховка без отрыва ручки и подъём пера на любом заметном переезде (порог привязан к шагу штриховки)
- **Пропуск цветов**, которых нет на изображении
- **Порядок слоёв перетаскиванием** с оценкой пути и времени по каждому слою
- **Режимы предпросмотра**: постеризованное изображение, ход ручки в реальных цветах, интерактивная 3D-**сфера Lab** с вашими ручками внутри цветового пространства
- **Баннер смены цвета**: когда GRBL уходит в `Hold` на `M0`, на весь экран появляется уведомление, на какую ручку переключиться; нажмите *Продолжить*, чтобы возобновить
- **Запуск каждого цвета отдельно** с вкладки «Станок». Вся цветная картинка отображается на рабочем поле, а у каждого слоя есть статус: *Ожидание / Отправка / Готово / Остановлено*
- Предпросмотр размещения точно соответствует тому, что отправляется на станок (смещение и масштаб)

## Использование

1. Перейдите в Deployments => Last deployments и откройте сайт.
2. Откройте вкладку **Цветная ручка**, загрузите изображение (перетаскиванием, `Ctrl+V` или кликом).
3. При необходимости откалибруйте палитру пипеткой (по факту не обязательно), настройте параметры.
4. На вкладке **Станок** подключитесь к станку

<img width="343" height="69" alt="image" src="https://github.com/user-attachments/assets/244ccc3e-bf12-4572-819c-adb0a47664f3" />

5. Сгенерируйте G-code и проверьте предпросмотр **Ход ручки**.

<img width="288" height="76" alt="image" src="https://github.com/user-attachments/assets/cd29185a-fafd-4ab9-b68a-80a2185b511c" />

6. Отправьте код на станок, поставив нужный цвет.
7. Когда появится баннер, смените цвет ручки и нажмите *Продолжить*.

## Требования

- ЧПУ на GRBL (проверено на 3018)
- Держатель для ручки с пружиной / подъёмом, многоцветная кнопочная ручка (8 цветов у меня работали нормально)
- Браузер с поддержкой Web Serial (Chrome / Edge)

## Примечания

- Без белого цвета и смешивания результат выглядит как постеризованная печать в стиле линогравюры, а не как фотография. Для этой техники так и должно быть.
- Калибруйте цвета на той бумаге, которую будете использовать: реальные чернила темнее и тусклее, чем их номинальный цвет.
